# password-strength-checker
🔐 Password Strength Checker

A beginner-friendly Python project that evaluates password strength using basic security criteria.

Features

* Checks password length
* Detects uppercase and lowercase letters
* Checks for numerical digits
* Checks for special characters
* Provides suggestions for improvement

Technologies Used

* Python
* String handling
* Conditional statements
* Functions and loops

How to Run

python main.py

* Conditional statements
* Loops
* String manipulation
* Basic password security concepts
